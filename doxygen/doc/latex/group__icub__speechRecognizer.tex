The module based on Microsoft Speech API. It is made to recognize speech based on runtime grammar in different formats\+: XML W3C specification "{}custom"{} simple format closed to the one used in the CSLU RAD Toolkit. The class Robot\+Grammar\+Manager maintains a dictionary of various vocabulories usefull in HRI (Objects, Agents, Actions...) which can be expanded at runtime and can be used in grammars.\hypertarget{group__windows-tts_lib_sec}{}\doxysubsection{\texorpdfstring{Libraries}{Libraries}}\label{group__windows-tts_lib_sec}
